# Duo Grip Lab

折叠设备远程桌面的交互概念网页：内屏上方约 ¾ 用于 Monitor，下方约 ¼ 是常驻触摸键盘，背面外屏是独立 Touchpad。

## 本地运行

```sh
python3 -m http.server 8743 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:8743`。无需 npm 安装或构建；不要直接双击 HTML，浏览器的 ES modules 需要 HTTP。

## 体验

- 3D 模型支持正面、背面、环绕与拖动旋转；可切换外屏在右侧或下方的两种握法、暂停动画。
- 双手拇指操作正面下方键盘；食指与中指操作背面外屏。模型仅为概念示意，不代表精确设备尺寸或验证过的人体工学结论。
- 网页原型可把独立触控板移到内屏四边。先点 `⌘` → `A` 全选文稿，再点字母；支持 Shift、退格、换行、箭头和演示剪贴板。
- **按 P 或点击“接管触控板”进入，Esc 退出。** 接管后系统指针隐藏，触控板直接移动 Monitor 中的光标，无需按住面板；点按为左键、按下后移动为拖拽、双指滚动文稿、系统辅助点按为右键。关闭/切换窗口或标签页会释放接管。
- 接管时普通物理键盘按键输入演示文稿，支持字母、Shift、退格、换行、方向键和演示内的 ⌘A/C/V/Z。右键菜单按虚拟光标位置选择。系统保留快捷键/手势仍由 macOS / 浏览器处理；这不是全局输入拦截器，也不是完整远控输入法。
- 网页接管使用 [Pointer Lock](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)，需要浏览器允许。若嵌入预览不支持，在独立 Edge / Chrome 窗口打开同一地址。未接管时仍可在可见面板按下滑动演示；移动端只保留面板触摸方式。
- 设计对比区解释内屏集中操作与内外屏分工的空间差异，并列出疲劳、误触与精度等待验证问题。

## 边界

桌面、输入与剪贴板均为当前页面内存中的模拟，刷新会重置。不读取或控制真实电脑，不发送输入数据。真实外屏支持还需公开 API 与设备验证。

## 文件

- `dist/index.html`：页面结构与设计叙事。
- `dist/style.css`：桌面与手机布局。
- `dist/app.js`：网页键盘、文稿、指针及触控板。
- `dist/input-capture.js`：Pointer Lock、相对输入与退出/失焦释放。
- `dist/grip-scene.js`：Three.js 程序化设备、关节手指和握持动画。
- `dist/vendor/`：Three.js 0.180.0 及其 MIT 许可证；运行时不依赖 CDN。

此仓库仅包含展示网页。原生 SwiftUI / Mac 调试原型独立维护。

## 已有检查记录

初版浏览器中验证了键盘回显、右键菜单、清空与重置、相对指针移动、外屏位置切换、3D 正反视角与两种握法，以及 390px 宽页面无横向溢出。真实设备多指输入与人体工学收益尚未验证。

本轮在独立 Edge 中确认 P 进入接管、Esc 释放；内嵌预览拒绝 Pointer Lock 时显示切换浏览器提示。接管界面按窗口可用空间完整显示两块虚拟屏幕。未新增自动化测试，实际触控板多指手感仍需使用者体验。
